# Practice exam

A 240-minute simulation of the B part. The points match the sample task: Java 15, JavaFX 10, backend 15, frontend 15, CSS 10.

## How to run it

1. Set a timer for 240 minutes. Do not pause it.
2. Read all five tasks before you type.
3. Create a new folder, for example `~/practice-run-01`.
4. Keep the reference repository open in a second window. Copy the closest template, then adapt it.
5. Write down the time when you finish each part.
6. At the end, run the acceptance checks in `practice/tasks.md`.
7. Score yourself with the table below.

## Time budget

| Part | Minutes | Points |
|---|---:|---:|
| Read the tasks and set up | 10 | 0 |
| Java console | 45 | 15 |
| JavaFX | 35 | 10 |
| Backend and SQL | 55 | 15 |
| React | 55 | 15 |
| CSS and responsive check | 30 | 10 |
| Buffer and submission | 10 | 0 |

The backend and React parts take the longest because you have to start two servers and check the browser. Start the backend before the React part, not after.

## Scoring

Give yourself points only for behavior you can show:

- The program compiles and runs.
- The endpoint returns the expected JSON.
- The page loads without a console error.
- The layout works at 375px wide.
- The output file has the expected rows.

A feature that is half written scores zero in an exam. Finish the easy parts first.

## What to do when you get stuck

- Print the raw data before you parse it.
- Call the API in the browser or with `curl` before you touch React.
- Check the browser console and the network tab.
- Compare your file with the template line by line. Do not rewrite from memory.
- Move to the next part after 10 minutes without progress. Come back with fresh eyes.

## After the run

Write three lines:

1. Which part took longer than planned?
2. Which error cost the most time?
3. Which template did you not find fast enough?

Fix the repository so the next run is faster. Add a note to the copy-paste index or the cheat sheet that would have saved you.
