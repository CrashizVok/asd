# Lists

HTML topic · Exam Wiki

```html
<ul>
  <li>Free cancel</li>
  <li>Breakfast included</li>
</ul>

<ol>
  <li>Pick a date</li>
  <li>Choose a room</li>
</ol>

<dl>
  <dt>Check-in</dt>
  <dd>From 14:00</dd>
</dl>
```

`ul` for unordered items, `ol` when order matters, `dl` for term and description pairs. Only `li` may sit directly inside `ul` or `ol`.
