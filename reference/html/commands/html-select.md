# <select>

HTML command · Forms

A drop-down list. Each choice is an option. Use size or multiple for a list box.

## Syntax

```html
<select name="city"><option>Budapest</option></select>
```

## Example

```html
<label for="city">City</label>
<select id="city" name="city">
  <option value="budapest">Budapest</option>
  <option value="debrecen">Debrecen</option>
</select>
```
