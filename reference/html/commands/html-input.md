# <input>

HTML command · Forms

A form control. type changes the control: text, email, password, number, date, checkbox, radio, file, submit, and more.

## Syntax

```html
<input type="text" name="first_name">
```

## Example

```html
<input type="text" name="first_name" placeholder="Anna" required>
<input type="email" name="email">
<input type="date" name="start_date">
<input type="number" name="adults" min="1" value="2">
```
