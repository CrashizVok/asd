# <meta>

HTML command · Document

Provides metadata. charset sets the encoding, viewport controls mobile scaling, and name/content pairs describe the page.

## Syntax

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

## Example

```html
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="Hotel booking exam project">
```
