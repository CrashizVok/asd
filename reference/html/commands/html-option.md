# <option>

HTML command · Forms

One choice inside select or datalist. value is what the form sends; the text is what the user sees.

## Syntax

```html
<option value="x">Label</option>
```

## Example

```html
<select name="stars">
  <option value="3">3 stars</option>
  <option value="4" selected>4 stars</option>
</select>
```
