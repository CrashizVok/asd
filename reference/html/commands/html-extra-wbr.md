# <wbr>

HTML command · Semantic text

Marks an optional line break inside a long word or URL. The browser breaks there only when the line is too narrow.

## Syntax

```html
<wbr>
```

## Example

```html
<p>Docs: /reference/<wbr>html-attributes/<wbr>global</p>
<!-- the URL stays one word, the breaks are only opportunities -->
```
