# title attribute

HTML command · Global attributes

Adds an advisory tooltip. It also supplies the description for abbr, but it never replaces a visible label.

## Syntax

```html
<abbr title="HyperText Markup Language">HTML</abbr>
```

## Example

```html
<abbr title="HyperText Markup Language">HTML</abbr>

<button title="Close without saving">X</button>
<!-- tooltips do not appear on touch screens, so never hide needed text here -->
```
