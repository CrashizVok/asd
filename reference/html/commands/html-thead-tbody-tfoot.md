# <thead>, <tbody>, <tfoot>

HTML command · Tables

Groups table rows into header, body, and footer. It helps styling and screen readers.

## Syntax

```html
<thead>...</thead><tbody>...</tbody><tfoot>...</tfoot>
```

## Example

```html
<table>
  <thead><tr><th>Guest</th><th>Nights</th></tr></thead>
  <tbody><tr><td>Anna</td><td>3</td></tr></tbody>
  <tfoot><tr><td>Total</td><td>3</td></tr></tfoot>
</table>
```
