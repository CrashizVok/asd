# <svg>

HTML command · Links and media

Draws vector graphics with XML elements. It scales without losing quality.

## Syntax

```html
<svg width="40" height="40">...</svg>
```

## Example

```html
<svg width="40" height="40" viewBox="0 0 40 40">
  <circle cx="20" cy="20" r="16" fill="teal" />
</svg>
```
