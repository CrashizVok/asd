# <optgroup>

HTML command · Forms

Groups options inside a select. The label is shown as a non-selectable heading.

## Syntax

```html
<optgroup label="Group"><option>...</option></optgroup>
```

## Example

```html
<select name="city">
  <optgroup label="Hungary">
    <option>Budapest</option>
    <option>Debrecen</option>
  </optgroup>
</select>
```
