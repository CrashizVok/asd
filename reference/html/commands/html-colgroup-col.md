# <colgroup> and <col>

HTML command · Tables

Defines groups of columns for styling. It goes after caption and before thead.

## Syntax

```html
<colgroup><col span="2"></colgroup>
```

## Example

```html
<table>
  <colgroup>
    <col style="background:#1f6feb33">
    <col span="2">
  </colgroup>
  ...
</table>
```
