# <details> and <summary>

HTML command · Interactive

A native expandable section. The summary is always visible; the rest opens on click.

## Syntax

```html
<details><summary>More</summary>Hidden text</details>
```

## Example

```html
<details>
  <summary>Cancel policy</summary>
  <p>Free cancellation up to 48 hours before arrival.</p>
</details>
```
