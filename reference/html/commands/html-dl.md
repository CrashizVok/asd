# <dl>, <dt>, <dd>

HTML command · Lists

A description list: dt is the term, dd is the description. Useful for key/value pairs.

## Syntax

```html
<dl><dt>Term</dt><dd>Definition</dd></dl>
```

## Example

```html
<dl>
  <dt>Check-in</dt><dd>14:00</dd>
  <dt>Check-out</dt><dd>10:00</dd>
</dl>
```
