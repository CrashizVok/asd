# <main>

HTML command · Structure

The main content of the page. There should be only one main element per page, and it must not be inside header, nav, aside, or footer.

## Syntax

```html
<main> ... </main>
```

## Example

```html
<main id="content">
  <h1>Hotels</h1>
  <p>Choose a hotel.</p>
</main>
```
