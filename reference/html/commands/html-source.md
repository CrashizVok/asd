# <source>

HTML command · Links and media

Provides a media source for picture, video, or audio. The browser picks the first format it supports.

## Syntax

```html
<source src="movie.mp4" type="video/mp4">
```

## Example

```html
<video controls>
  <source src="tour.mp4" type="video/mp4">
  <source src="tour.webm" type="video/webm">
</video>
```
