# <section>

HTML command · Structure

A thematic group of content, usually with its own heading. Do not use it just to wrap a div.

## Syntax

```html
<section> ... </section>
```

## Example

```html
<section aria-labelledby="offers">
  <h2 id="offers">Offers</h2>
  <p>Summer discounts.</p>
</section>
```
