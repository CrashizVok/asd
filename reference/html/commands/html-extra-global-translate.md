# translate

HTML command · Global attributes

Tells automatic translation to skip an element. Keep brand names and code samples untranslated.

## Syntax

```html
translate="no"
```

## Example

```html
<!-- machine translation skips these names and this code -->
<p>Book at <span translate="no">Hotel Belvedere</span> today.</p>
<code translate="no">room_price * nights</code>
```
