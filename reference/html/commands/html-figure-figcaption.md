# <figure> and <figcaption>

HTML command · Interactive

A self-contained figure with an optional caption. The caption can be above or below the content.

## Syntax

```html
<figure><img ...><figcaption>Caption</figcaption></figure>
```

## Example

```html
<figure>
  <img src="hotel.jpg" alt="Danube View">
  <figcaption>Danube View, Budapest</figcaption>
</figure>
```
