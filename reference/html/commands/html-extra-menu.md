# <menu>

HTML command · Semantic text

A list of commands or toolbar actions. It is not the navigation menu of a site, nav with a list is still the right element for that.

## Syntax

```html
<menu><li><button>Save</button></li></menu>
```

## Example

```html
<menu>
  <li><button onclick="save()">Save</button></li>
  <li><button onclick="cancel()">Cancel</button></li>
</menu>
<!-- menu means a list of commands, not links between pages -->
```
