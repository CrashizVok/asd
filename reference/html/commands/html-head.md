# <head>

HTML command · Document

Holds metadata: title, character set, viewport, styles, scripts, and icons. It is not shown in the page body.

## Syntax

```html
<head> ... </head>
```

## Example

```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Bookings</title>
  <link rel="stylesheet" href="style.css">
</head>
```
