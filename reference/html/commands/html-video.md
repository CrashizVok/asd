# <video>

HTML command · Links and media

Embeds a video. controls shows play, pause, and volume. Add fallback text for old browsers.

## Syntax

```html
<video controls src="movie.mp4"></video>
```

## Example

```html
<video controls width="640" poster="cover.jpg">
  <source src="tour.mp4" type="video/mp4">
  Your browser does not support video.
</video>
```
