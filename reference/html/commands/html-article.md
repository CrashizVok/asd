# <article>

HTML command · Structure

A self-contained piece of content that could be published on its own, such as a blog post, card, or comment.

## Syntax

```html
<article> ... </article>
```

## Example

```html
<article class="hotel-card">
  <h2>Danube View</h2>
  <p>Four stars in Budapest.</p>
</article>
```
