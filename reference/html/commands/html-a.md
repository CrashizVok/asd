# <a>

HTML command · Links and media

Creates a link. href can point to a page, a file, an email address, a phone number, or an id on the same page.

## Syntax

```html
<a href="page.html">Text</a>
```

## Example

```html
<a href="/hotels">Hotels</a>
<a href="#top">Back to top</a>
<a href="mailto:info@example.com">Email</a>
```
