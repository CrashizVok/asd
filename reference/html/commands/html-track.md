# <track>

HTML command · Links and media

Adds subtitles, captions, or descriptions to video or audio.

## Syntax

```html
<track src="subs.vtt" kind="subtitles" srclang="en" label="English">
```

## Example

```html
<video controls>
  <source src="tour.mp4" type="video/mp4">
  <track src="tour-en.vtt" kind="subtitles" srclang="en" label="English">
</video>
```
