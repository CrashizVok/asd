# lang

HTML command · Global attributes

Marks the language of an element. Screen readers pick the right pronunciation, and browsers hyphenate and spell check with the right dictionary.

## Syntax

```html
<span lang="de">Guten Tag</span>
```

## Example

```html
<html lang="en">
  <body>
    <p>The German word <span lang="de">Zimmer</span> means room.</p>
  </body>
</html>
<!-- one lang on html, then override it per foreign phrase -->
```
