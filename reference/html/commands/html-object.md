# <object>

HTML command · Links and media

Embeds an external resource such as a PDF. Fallback content goes inside the element.

## Syntax

```html
<object data="file.pdf" type="application/pdf"></object>
```

## Example

```html
<object data="menu.pdf" type="application/pdf" width="600" height="400">
  <a href="menu.pdf">Download the menu</a>
</object>
```
