# <hgroup>

HTML command · Semantic text

Groups a heading with its subtitle so the document outline keeps one entry. The paragraph is not a heading and is not announced as one.

## Syntax

```html
<hgroup><h1>Title</h1><p>Subtitle</p></hgroup>
```

## Example

```html
<!-- one outline entry, not two headings -->
<hgroup>
  <h1>Hotel bookings</h1>
  <p>Exam project, 2026</p>
</hgroup>
```
