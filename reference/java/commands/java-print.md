# System.out.println

Java command · Basics

Prints a value and moves to a new line. print does not move to a new line; printf formats.

## Syntax

```java
System.out.println(value);
```

## Example

```java
System.out.println("Hello");
System.out.print("No newline");
System.out.printf("%s is %d years old%n", "Anna", 22);
```
