# TreeSet

Java command · Collections

A set that keeps values sorted and unique.

## Syntax

```java
new TreeSet<String>()
```

## Example

```java
import java.util.TreeSet;

TreeSet<String> names = new TreeSet<>();
names.add("Cara");
names.add("Anna");
names.add("Ben");

System.out.println(names); // [Anna, Ben, Cara]
```
