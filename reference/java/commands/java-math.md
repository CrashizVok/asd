# Math

Java command · Numbers

Math has static helpers: max, min, abs, round, floor, ceil, pow, sqrt, random.

## Syntax

```java
Math.max(a, b)
Math.round(x)
```

## Example

```java
System.out.println(Math.max(3, 9)); // 9
System.out.println(Math.abs(-4));   // 4
System.out.println(Math.round(4.6)); // 5
System.out.println(Math.pow(2, 8)); // 256.0
```
