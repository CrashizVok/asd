# variables and types

Java command · Basics

Java is statically typed. Common primitives: int, long, double, boolean, char. String is a class.

## Syntax

```java
int count = 3;
double price = 12.5;
boolean ok = true;
```

## Example

```java
int adults = 2;
double price = 89.90;
boolean paid = false;
char grade = 'A';
String city = "Budapest";

System.out.println(adults + " adults");
```
