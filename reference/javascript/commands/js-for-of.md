# for...of

JavaScript command · Control flow

Iterates over the values of an array, string, Map, or Set. Prefer it when you need the values.

## Syntax

```js
for (const item of array) { ... }
```

## Example

```js
const guests = ["Anna", "Ben", "Cara"];

for (const guest of guests) {
  console.log(guest);
}
```
