# array creation and indexing

JavaScript command · Arrays

Arrays hold ordered values. Indexes start at 0. length is the number of items.

## Syntax

```js
const list = [1, 2, 3];
list[0]
```

## Example

```js
const hotels = ["Danube View", "Lake Garden", "City Loft"];

console.log(hotels[0]);      // Danube View
console.log(hotels.length);   // 3
console.log(hotels.at(-1));   // City Loft
```
