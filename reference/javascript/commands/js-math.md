# Math

JavaScript command · Numbers and Math

Math holds number helpers: round, floor, ceil, abs, min, max, random, pow, sqrt.

## Syntax

```js
Math.round(x)
Math.max(...values)
```

## Example

```js
console.log(Math.round(4.6)); // 5
console.log(Math.floor(4.9)); // 4
console.log(Math.ceil(4.1));  // 5
console.log(Math.max(3, 9, 2)); // 9
console.log(Math.random());    // 0 to below 1
```
