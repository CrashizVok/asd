# typeof

JavaScript command · Basics

Returns the type as a string: string, number, boolean, undefined, object, function, symbol, or bigint. null reports object, a known quirk.

## Syntax

```js
typeof value
```

## Example

```js
typeof "text";      // "string"
typeof 42;          // "number"
typeof true;        // "boolean"
typeof undefined;   // "undefined"
typeof null;        // "object"
typeof [];          // "object"
typeof function(){}; // "function"
```
