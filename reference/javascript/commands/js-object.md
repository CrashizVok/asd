# object literal

JavaScript command · Objects

Groups related values under named keys. Read with dot or bracket notation.

## Syntax

```js
const obj = { key: value };
```

## Example

```js
const hotel = {
  name: "Danube View",
  stars: 4,
  city: "Budapest"
};

console.log(hotel.name);
console.log(hotel["stars"]);
```
