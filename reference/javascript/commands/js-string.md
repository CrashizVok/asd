# string basics

JavaScript command · Strings

Strings are immutable text values. Use single, double, or backtick quotes.

## Syntax

```js
const text = "hello";
```

## Example

```js
const first = "Anna";
const last = "Kovacs";
const full = `${first} ${last}`;

console.log(full.length); // 10
console.log(full.toUpperCase()); // ANNA KOVACS
```
