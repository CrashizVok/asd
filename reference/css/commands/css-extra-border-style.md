# border-style

CSS command · Borders

Picks the line style per side: solid, dashed, dotted, double, groove, ridge, inset, outset or none. none hides the width without removing it.

## Syntax

```css
border-style: solid dashed;
```

## Example

```css
.notice {
  border-width: 2px;
  /* top and bottom solid, left and right dashed */
  border-style: solid dashed;
  border-color: #b00020;
}
```
