# [attribute] selector

CSS command · Selectors

Selects elements that have an attribute, or an attribute with a specific value.

## Syntax

```css
input[type="email"] { border-color: teal; }
```

## Example

```css
a[target="_blank"] {
  text-decoration: underline;
}

input[type="date"] {
  font-family: inherit;
}
```
