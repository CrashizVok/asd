# ::placeholder

CSS command · Typography

Styles the placeholder text of inputs and textareas. Only a small set of properties applies, and Firefox lowers opacity by default.

## Syntax

```css
::placeholder { color: #6b7280; }
```

## Example

```css
input::placeholder {
  color: #6b7280;
  /* Firefox reduces opacity on its own */
  opacity: 1;
}
```
