# accent-color

CSS command · Colour

Recolours the browser drawn parts of checkboxes, radios, range sliders and progress bars. One line instead of custom widgets.

## Syntax

```css
accent-color: #1f6feb;
```

## Example

```css
/* one line instead of custom checkbox widgets */
input[type="checkbox"],
input[type="radio"],
input[type="range"] {
  accent-color: #1f6feb;
}
```
