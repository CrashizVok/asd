# column-rule

CSS command · Layout

Draws a line between multi column boxes. It sits in the middle of column-gap and takes no layout space.

## Syntax

```css
column-rule: 1px solid #d0d7de;
```

## Example

```css
.terms {
  column-count: 2;
  column-gap: 2rem;
  /* the rule is centred in the gap */
  column-rule: 1px solid #d0d7de;
}
```
