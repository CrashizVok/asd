# position: static

CSS command · Positioning

The default. The box stays in normal flow and every offset is ignored.

## Syntax

```css
.box { position: static; }
```

## Example

```css
.box {
  position: static;   /* the initial value; writing it is only a reminder */
  top: 40px;          /* has no effect here */
  left: 40px;         /* has no effect here */
}
```
