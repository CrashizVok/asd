# text-underline-offset

CSS command · Typography

Moves the underline away from the baseline so descenders stay readable. text-decoration-thickness sets the line weight.

## Syntax

```css
text-underline-offset: 0.2em;
```

## Example

```css
a {
  text-decoration: underline;
  /* gap under the glyphs, and a heavier line */
  text-underline-offset: 0.2em;
  text-decoration-thickness: 2px;
}
```
