# linear-gradient and radial-gradient

CSS command · Background

Creates a gradient image. Use it as a background or overlay.

## Syntax

```css
background: linear-gradient(135deg, #0f766e, #0b0f14);
```

## Example

```css
.button {
  background: linear-gradient(135deg, #14b8a6, #0f766e);
}

.hero {
  background: radial-gradient(circle at top, #1f2937, #0b0f14 60%);
}
```
