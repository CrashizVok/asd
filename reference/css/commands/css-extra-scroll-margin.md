# scroll-margin-top

CSS command · Scrolling

Offsets where an element lands when scrolled into view by an anchor or scrollIntoView. It fixes links hidden under a sticky header.

## Syntax

```css
scroll-margin-top: 5rem;
```

## Example

```css
section[id] {
  /* the sticky header is 4.5rem tall, keep the heading visible */
  scroll-margin-top: 5rem;
}
```
