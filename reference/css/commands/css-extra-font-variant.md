# font-variant

CSS command · Typography

Turns on typographic variants such as small caps. font-variant-numeric controls figure width in aligned columns.

## Syntax

```css
font-variant: small-caps;
```

## Example

```css
.label {
  /* small caps usually need a little letter spacing */
  font-variant: small-caps;
  letter-spacing: 0.04em;
}
.price { font-variant-numeric: tabular-nums; }
```
