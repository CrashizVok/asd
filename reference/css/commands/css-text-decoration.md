# text-decoration

CSS command · Typography

Adds or removes underline, overline, or line-through. You can also set colour and style.

## Syntax

```css
text-decoration: none;
```

## Example

```css
a {
  text-decoration: none;
}

a:hover {
  text-decoration: underline;
}

.old-price {
  text-decoration: line-through;
}
```
