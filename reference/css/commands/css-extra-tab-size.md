# tab-size

CSS command · Typography

Sets how wide a tab character renders, mostly inside pre and textarea. A number counts spaces, a length is absolute.

## Syntax

```css
tab-size: 4;
```

## Example

```css
pre, code {
  /* four space widths per tab, keeps pasted code aligned */
  tab-size: 4;
}
textarea { tab-size: 2; }
```
