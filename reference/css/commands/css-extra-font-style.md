# font-style

CSS command · Typography

Selects an italic or oblique face, or keeps text upright. Oblique accepts an angle in fonts that support it.

## Syntax

```css
font-style: italic;
```

## Example

```css
em, .emphasis { font-style: italic; }

.pull-quote {
  /* slanted by 12 degrees where the font allows it */
  font-style: oblique 12deg;
}
```
