# flex-flow

CSS command · Flex

Shorthand for flex-direction and flex-wrap. row wrap is the common base for a responsive toolbar.

## Syntax

```css
flex-flow: row wrap;
```

## Example

```css
.toolbar {
  display: flex;
  /* direction first, then wrapping */
  flex-flow: row wrap;
  gap: 0.5rem;
}
```
