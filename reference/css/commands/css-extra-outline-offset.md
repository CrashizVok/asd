# outline-offset

CSS command · Borders

Pushes the outline away from the border box. A negative value pulls it inside, where it can sit on the content.

## Syntax

```css
outline-offset: 3px;
```

## Example

```css
.card:focus-visible {
  outline: 2px solid #1f6feb;
  /* space between the border and the ring */
  outline-offset: 3px;
}
```
