# justify-content

CSS command · Flexbox

Spreads items along the main axis: flex-start, center, flex-end, space-between, space-around, space-evenly.

## Syntax

```css
justify-content: space-between;
```

## Example

```css
.topbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
```
