# :nth-child()

CSS command · Selectors

Selects elements by their position among siblings. odd, even, and formulas like 2n+1 work.

## Syntax

```css
li:nth-child(2n) { background: #f5f5f5; }
```

## Example

```css
tbody tr:nth-child(even) {
  background: #f1f5f9;
}

li:first-child {
  font-weight: 700;
}
```
