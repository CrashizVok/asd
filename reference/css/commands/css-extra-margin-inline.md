# margin-inline

CSS command · Layout

Sets the start and end margin on the inline axis. margin-inline auto centres a fixed width block, the same as the left and right auto pair.

## Syntax

```css
margin-inline: auto;
```

## Example

```css
.sheet {
  max-inline-size: 60rem;
  /* both inline margins, direction aware */
  margin-inline: auto;
}
.note {
  margin-block: 1rem 2rem; /* top and bottom */
}
```
