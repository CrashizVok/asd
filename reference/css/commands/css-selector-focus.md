# :focus and :focus-visible

CSS command · Selectors

Applies styles when the element has keyboard or mouse focus. :focus-visible is usually better for keyboard rings.

## Syntax

```css
input:focus { outline: 2px solid teal; }
```

## Example

```css
a:focus-visible,
button:focus-visible {
  outline: 3px solid #5eead4;
  outline-offset: 3px;
}
```
