# float and clear

CSS command · Layout

Moves an element to the left or right and lets text wrap around it. Modern layouts use flex or grid instead.

## Syntax

```css
float: left; clear: both;
```

## Example

```css
.photo {
  float: left;
  margin: 0 16px 8px 0;
}

.footer {
  clear: both;
}
```
