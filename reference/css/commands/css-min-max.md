# min-width, max-width, min-height, max-height

CSS command · Box model

Sets limits so an element can grow or shrink but never past the limit.

## Syntax

```css
.panel { max-width: 1100px; min-height: 100vh; }
```

## Example

```css
.panel {
  width: 100%;
  max-width: 1100px;
  min-height: 60vh;
  margin: 0 auto;
}
```
