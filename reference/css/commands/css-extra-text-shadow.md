# text-shadow

CSS command · Typography

Draws a shadow behind glyphs: offset x, offset y, blur, colour. It follows the text shape and costs no layout.

## Syntax

```css
text-shadow: 0 1px 2px rgba(0, 0, 0, 0.4);
```

## Example

```css
.hero-title {
  color: #fff;
  /* x, y, blur, colour; a dark halo keeps it readable on photos */
  text-shadow: 0 1px 2px rgba(0, 0, 0, 0.55);
}
```
